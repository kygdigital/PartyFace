## 2026-05-31

- Initialized PRD workspace for PartyFace.
- Captured origin signal: user received a fun but lower-quality birthday video/card asset and wants to rebuild the experience with ComfyUI as a higher-quality creative backend.
- Captured inspiration inputs:

- User identified JibJab as the first competitive benchmark.
- User value signal: received birthday video felt fun because it personalized specific people into lively scenery with music.
- User pain signal: existing experience felt low quality because image generation/compositing was not great and asked for manual attributes such as skin color instead of detecting or adapting intelligently.
- Initial product wedge: use ComfyUI-backed image/video generation to create higher-quality, promptable, multi-iteration personalized birthday media instead of locking users into a small set of rigid templates.
- Competitive benchmark source added: `https://www.jibjab.com`.
- JibJab benchmark notes from official site/help: JibJab positions around personalized Ecards/Videos, "Starring You" face personalization, AI Image Packs, theme/pack selection, face upload or face library selection, skin tone selection, and generated packs of 8 images.
- Created competitive teardown artifact: `competitive-teardown-jibjab.md`.
- Product scope decision: first validation should support both premium still birthday cards/posters and short animated/video outputs, because ComfyUI MCP reduces generation implementation effort; PartyFace's main work is the user workflow and front end around ComfyUI.
- MVP subject-count decision: support two Subjects first. This preserves the emotional/social birthday hook while avoiding arbitrary multi-person scene complexity in v1.
- Subject slot labeling decision: use neutral labels such as Person 1 and Person 2 instead of role-specific labels like Birthday Person and Co-star.
- Template strategy decision: include 3-5 supported starter templates in MVP for discovery and getting started, while allowing customization from those templates.
